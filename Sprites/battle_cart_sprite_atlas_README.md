# Battle Cart Sprite Atlas

Use `battle_cart_sprite_atlas.png` with `battle_cart_sprite_atlas.json`.

Sprites:
- cart: 128x64
- warrior: 32x32
- gatherer: 32x32
- ore: 32x32
- tree: 32x32
- wolf: 32x32
- blood_puddle: 32x32

Recommended usage:
- Load the atlas image once.
- Use JSON coordinates to draw each sprite from the atlas.
- The background is transparent.
- Keep pixel art sharp with nearest-neighbor scaling / image-rendering: pixelated.
